# Pořadí implementace

1. **Základ a průchozí rybolov**: projekt, přístupné UI, manifest grafiky, title, jedna česká scéna, výbava, rybolov, karta. Výstup: dítě dokončí výpravu bez debug tlačítek.
2. **Učení a ukládání**: typované pojmy, CZ/EN audio rozhraní, scénář, důkazy mastery, návraty, save a resume. Výstup: po reloadu pokračuje správný stav a slova se vracejí v jiném kontextu.
3. **Mluvení a rodina**: režim s dospělým, dobrovolné procvičení, speech adapter, jasný původ ověření, dosažená hlasová pečeť. Výstup: žádné falešné automatické skóre.
4. **Skutečné odměny**: rodičovské nastavení, snapshot výzev, evidence, jednorázové předání, import konflikt. Výstup: žádné dvojité nároky při běžném používání jednoho zařízení.
5. **Zbytek světa**: všech 8 výprav, Klárka a malí tvorové, Iowa, Příbram, cyklistika, děda a babi, mapa a atlas.
6. **Zvuk, animace a finální kontrola**: zkontrolované nahrávky, optimalizované textury, responsive kompozice, reduced motion, E2E průchody a výkon.

Automatické hodnocení české dětské výslovnosti je oddělený experiment. Neodkládej kvůli němu funkční režim s rodičem a nezaměňuj dostupnost ASR za vyřešenou evaluaci výslovnosti.

## Aktuální stav

Připravený koncept, implementační prompt, obsahová data, grafická sada a kontrolní nástroje. Milníky herní implementace ještě nejsou realizované. Audio soubory a produkční speech provider nejsou vyrobené ani nakonfigurované.
